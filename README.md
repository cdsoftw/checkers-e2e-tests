# Checkers - E2E Tests
## [Cole Dapprich](https://www.linkedin.com/in/cdsoft/)

This repository contains a detailed end-to-end test plan for a simple browser-based [checkers game](https://www.gamesforthebrain.com/game/checkers/). It also contains a Node.js/TypeScript skeleton for a Playwright test codebase, as well as a few test cases created within a 30-45 minute time limit.

Created for a technical interview at a leading defense startup.
